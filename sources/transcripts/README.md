# Transcripts

One file per source, named after the source id in `src/data/sources.ts` (for example `kobe-81-espn-retro.md`).

Each file starts with the source's title, link and date, then the transcript with timestamps where they are known:

```
# Title of the video or episode
Link: https://...
Published: 2024-01-22

[0:00] ...
[12:34] ...
```

These files are the record of what a source actually says, so a narrative's citation can always be checked against them.
